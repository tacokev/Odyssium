# Odyssium

Stream your favorite Adventures in Odyssey club episodes simply by logging in to the official website.

## Features

- Stream episodes from the Adventures in Odyssey Club
- Background playback
- Search episodes
- Login support
- Cache
- Skip silence
- Audio normalization
- Adjust tempo/pitch
- Dynamic theme
- Localization
- Android Auto support
- Material 3
